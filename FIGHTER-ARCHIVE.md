# VERSUS fighter archive

VERSUS now opens as a UFC career archive. `/fighters` offers name/nickname search, division filters, and name/wins/reach sorting across 500 fighters. The additional 300 athletes are selected from the existing July 7, 2026 UFC/UFCStats archive and completed UFC bout records. Missing measurements remain null; method splits are displayed only when they reconcile with career wins. Original 200 fighters retain their data and IDs. `/fighter/:id` shows the fighter’s record, measured statistics, recent recorded results, original source, and snapshot date. Users can save a favorite through the existing account profile API without changing their other profile fields.

498 fighters have verified athlete-page portraits. Dynamic cards use larger photography, individual color treatments, and career photos where available. 33 featured fighters have 58 attributed UFC career/event photographs in a switchable profile gallery. Images fall back to portraits when unavailable, and portrait failures fall back to initials. Moment cards use event photography only when its event label matches the card. Historical images may include opponents; credit/context links accompany the gallery. Photo catalogs are recorded in `public/fighter-photo-sources.json` and `public/fighter-scene-sources.json`.

Profiles launch `/compare?a=:id&b=:id`. This compares measured career statistics, supports swapping sides and copying a shareable URL, and links back to both fighter profiles. Missing measurements remain unavailable. Comparisons explicitly explain snapshot differences, source scope, and different weight classes. No winning probability or simulated prediction entry is part of this flow. The old `/predictions` URL opens the new comparison tool; legacy saved picks remain in the database. Legacy matchup pages default to career facts, retain discussions, and link into the new stats tool.

Fantasy remains at `/fantasy`, with actual scheduled cards and existing official-result scoring. Moments now total 67; the second collection adds 30 historical wins with exact date, opponent, method and round from UFCStats fight records linked on each card. The shop totals 51 cosmetics, including 24 new frames, banners and titles, with search, price sorting, and owned/affordable filters. Original purchases and equipped items remain valid. Moments reward rules and free coin economics are unchanged.

`/suggestions` is a persistent community board: five categories, support votes, newest/most-supported sorting, and category/roadmap filters. The board shows the latest 200 public suggestions. Signed-in members may create at most five suggestions per rolling 24 hours, support/remove support once per account, and withdraw their own ideas. Owners can mark ideas Open, Planned, Completed, or Hidden. Withdrawing/hiding removes an idea from public results while keeping its stored record. Anonymous creation, foreign origins, invalid payloads, and unauthorized roadmap changes are rejected by the server. Text renders as text, not HTML.

Cloudflare deployment automatically applies migrations through `0014_more_collectibles.sql` before publishing through the existing deployment script. The new catalog migration was applied to the local development database only. Publishing requires pushing the saved commit to GitHub and a successful Cloudflare deployment.

Validation: TypeScript, production Cloudflare build, shop and Moments database integrity tests, request-security regression tests, and disposable local API checks for suggestions and new purchases. Browser checks cover archive search → profile → chosen stats comparison, source data, mobile layout, expanded catalogs, and the suggestions form. No existing user wallet or profile was changed during testing.
